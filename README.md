# THE NAZ FORMATION

A responsive, minimalist personal-brand website starter.

## Files
- `index.html` — public homepage
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `admin.html` — browser-local draft dashboard

## Before publishing
1. Replace the sample email address in `index.html`.
2. Replace Instagram, Facebook and YouTube URLs with your own profile links.
3. Replace sample portfolio blocks and journal posts with your own work.
4. The admin page is a local draft tool, not a secure, server-backed CMS. Do not treat it as a private secured admin panel. Drafts are saved only in the current browser and do not publish to the homepage.

## Free hosting with Cloudflare Pages
1. Create a free account at https://dash.cloudflare.com/
2. Open **Workers & Pages** → **Create** → **Pages** → **Upload assets**.
3. Upload the contents of this folder (the files inside it, not the ZIP).
4. Choose a project name, then deploy.
5. Cloudflare will provide a free `*.pages.dev` address.

You can also publish with Netlify Drop: https://app.netlify.com/drop
